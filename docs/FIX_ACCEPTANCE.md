## Что проверять владельцу

Открыть /admin/login. Счётчик «Заявки» доступен на всех страницах; открытие заявки отмечает прочтение только текущему сотруднику, бизнес-статус меняется отдельно. Новые заявки выделены, toast содержит номер/товар и ссылку без полного телефона. Первое открытие показывает накопленный счётчик без серии старых toast.

В товарах проверить правильную категорию. PHONE: RAM/память, экран, CPU, камеры, аккумулятор, SIM/ОС; LAPTOP: CPU/GPU/RAM, накопитель/тип, экран, ОС, вес. Общие поля — артикул, цвет, цена, наличие, скидка, рассрочка. У одной существующей комплектации есть предупреждение: изучить сохранённые чужие поля и подтвердить очистку только после проверки. Автоматически они не удалены.

Ссылка формируется автоматически и остаётся прежней после переименования. Артикул — уникальный код комплектации; новые коды нормализуются, старые массово не переписываются. OWNER → Журнал: фильтр логина/объекта/дат, раскрытие «было → стало»; старым записям неизвестный автор не выдумывается.

По 10: каталог/категории/скидки, товары/заявки/журнал/администраторы/редактор категорий/очередь доставки; избранное по 10 из ограниченных 100 ID. Навигация/селекторы и варианты товара не превращены в постраничные таблицы. Серверные totals считаются до LIMIT.
