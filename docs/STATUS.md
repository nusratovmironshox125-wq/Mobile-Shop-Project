# Состояние проекта

Проверка 8 ноября 2026 года, Asia/Tashkent. Основание — ТЗ 1.2. Исходная папка — `C:\JAVA darsliklar\MODULE-9\Real_Mobil_Shop_Sayt`.

| Этап | Состояние и следующий шаг |
| --- | --- |
| M0. Обследование | Исходный проект содержал каркас Maven без Git. JDK 21 установлен отдельно от системного JDK 17. PostgreSQL 18.4 на порту 5432 требует аутентификацию. В просмотренной Run Configuration нет явных ключей переопределения DataSource. PostgreSQL отвечает на 5432, пароль отсутствует в окружении Codex. Рабочую БД проверяет владелец. Тесты выполняются в отдельном кластере на 55432. |
| M1. Требования | Сохранено ТЗ 1.1 и backlog. Перед релизом владелец задаёт реальные контакты и каталог, текст обработки данных, период хранения и получателя Telegram. |
| M2. Проектирование | Есть архитектура, ERD, OpenAPI и модель угроз. Backend перенесён в слои config, controller, service, repository, entity, dto. ArchUnit закрепляет границы; уведомления и медиа используют интерфейсы. Фронтенд построен как адаптивная SPA, язык и тема сохраняются в браузере. |
| M3. Основа | На тестовой БД применяется миграция Flyway, работает проверка Hibernate, bootstrap OWNER, сессии, роли и CSRF. В профиле local Flyway включается явно после проверки схемы. CLI использует тот же JPA DataSource в транзакции read-only. Добавлен workflow для GitHub Actions. Его запуск на GitHub ожидает подключения репозитория. |
| M4. Каталог и админка | Работают категории, модели, комплектации, фото, скидки, рассрочка, поиск, фильтры, настройки и избранное. Проверена публикация, отзыв видимости и конфликт версии. |
| M5. Заявки | Работают заявка со снимком, повтор ключа, история, обработка и обезличивание. Outbox проверен с заглушкой. Реальная доставка ждёт тестового получателя. |
| M6. Качество | 9 тестов Maven, 110 HTTP-проверок и Edge прошли. AT-27 PASS. AT-26 для рабочей базы ожидает прогона владельца; изолированный прогон диагностики PASS. Матрица реальных устройств, Web Vitals, NAT-профиль, предел нагрузки и нагрузка 1 000/2 000 остаются для стенда. |
| M7. Выпуск | Нужны staging, домен, Java/PostgreSQL-хостинг, edge/WAF, мониторинг и испытание backup/restore/rollback. |

Локальная ветка `codex/real-mobil-shop`. Код для финального прогона ТЗ 1.2 — 631ee508577e1020957635e9d635286931e7ab31. Изменения документации коммитятся отдельно.

GitHub. Публичный профиль владельца подтверждён, но публичный 404 для предполагаемого репозитория не определяет наличие приватного репозитория. CLI GitHub отсутствует, сохранённая HTTPS-авторизация не найдена. Remote не настроен. После входа владельца нужно проверить аккаунт, наличие репозитория и права, затем связать и отправить локальную ветку. Локальные коммиты используют GitHub noreply, глобальная конфигурация Git не менялась.

Следующий шаг — владелец выполняет AT-26 по README. Перед миграцией рабочей схемы нужны её инвентаризация и резервная копия. Далее — отдельный стенд для оставшихся проверок. Руководства в README и DEPLOYMENT.
