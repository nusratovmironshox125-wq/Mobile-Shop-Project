# Решения

| Решение | Обоснование | Проверка |
| --- | --- | --- |
| Слои внутри пакета sayt | ТЗ 1.2. HTTP, сценарии, хранение и внешние адаптеры имеют отдельные границы | ArchitectureTests и полный локальный регресс |
| Локальная диагностика через JPA | Профиль local, CLI проверяет соединение в транзакции read-only. Миграции local включаются отдельно после согласования схемы | Изолированная БД распознаётся и отклоняется; AT-26 выполняет владелец |
| Одна установка обслуживает один магазин | ТЗ 1.2. Глобальная строка настроек, без клиентских аккаунтов | Изменение названия через настройки |
| Сохранить Maven Wrapper, Java 21 и Spring Boot 4.1.2 | Исходные параметры проекта. Используем JDK 21 из отдельной установки | Сборка и запуск JAR |
| React 19, TypeScript, Vite и same-origin | Сборка отдаётся Spring MVC, Node.js нужен при разработке и сборке | Прямые маршруты, CSRF через заголовок |
| Серверные сессии одного процесса | Хранение в контейнере, контроль auth_version в PostgreSQL для отзыва | Вход, смена пароля, отключение |
| PostgreSQL и Flyway | Схема из миграций. JPA для административных сущностей, параметризованный SQL для проекций, снимков и захвата outbox | Отдельный экземпляр PostgreSQL |
| UZS и BigDecimal | Снимок цены и SKU формируется сервером в транзакции | Цена по выбранной комплектации и конфликт цены |
| SPA SEO | Читаемые URL, title, canonical, robots и sitemap. Индексация и предпросмотры требуют отдельной проверки | Sitemap и прямые URL |
| Telegram подключаемый | Панель — основной канал. Outbox применяется, когда заданы токен и ID | Состояние канала и повтор FAILED |
| Изображения в файловом хранилище | Случайные ключи, декодирование и JPEG. Файлы каталога включаются в план backup | Проверки контента и публикации |
| Локальные лимиты одного процесса | Ограниченный Caffeine, таймауты, один экземпляр приложения до нагрузочных измерений | API-проверки. Распределённые лимиты и NAT-профиль ожидают стенда |
| Синтетический каталог создаёт тестовый сценарий | Запуск с пустой БД показывает пустую витрину. Демоданные не входят в миграции | Проверка на отдельной тестовой БД |

Проектные решения ТЗ о двух языках, отметке рассрочки, локальном избранном, роли OWNER и одной комплектации на заявку сохранены. Домен, модель хостинга, реальная политика обработки данных и содержимое магазина остаются зависимостями выпуска.

| Пара lead_read(admin_id,lead_id) | Просмотр отделён от бизнес-статуса и других сотрудников | PostgreSQL/HTTP: независимость, идемпотентность, CSRF |
| Polling оболочки 10 с | Существующий polling работал только в списке | Edge: 8.9 с, reconnect, две вкладки, page 3 |

| Строгие PHONE/LAPTOP и явная legacy-очистка | В одной старой записи смешаны значения | V2 сохраняет исходные значения, review flag, DTO validation |
